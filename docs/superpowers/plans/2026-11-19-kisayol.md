## Global Constraints

- Python 3.9+ uyumlu (3.10+ söz dizimi yok: `match`, `X | Y` tipleri yok; `from __future__ import annotations` kullanılabilir).
- Windows 10/11. Tek exe: PyInstaller `--onefile --windowed`.
- Lisans MIT, `Copyright (c) 2026 furkibayashi`.
- Ayar klasörü `%APPDATA%\KisaYol\`; dosyalar `settings.json`, `snippets.json`. Testler bu klasöre **asla** yazmaz (yollar parametre olarak verilir / `tmp_path`).
- Yazılan metin diske, loga, ağa gitmez. Tampon yalnızca bellekte, en fazla **64** karakter. Hiçbir modül ağ bağlantısı kurmaz.
- Tetikleyici: en az 2 karakter, boşluk/satır sonu yok, benzersiz, büyük/küçük harfe duyarlı.
- Sembollü tetikleyici = ilk karakter `str.isalnum()` değil → anında genişler. Sembolsüz = ilk karakter alnum → kelime başında + bitiş karakterinde genişler. **Sembolsüz tetikleyici tamamen alnum olmalıdır** (plan kararı; kelime ayrıştırması buna dayanır).
- Bitiş karakterleri: boşluk ve `. , ! ? : ; ) ] } " '`. Enter ve Tab bitiş karakteri değildir, tamponu sıfırlar.
- Değişkenler: `{tarih}`/`{date}`, `{saat}`/`{time}`, `{pano}`/`{clipboard}`, `{imleç}`/`{cursor}`; `{tarih:FMT}`, `{saat:FMT}`; `{{` `}}` kaçış; tanınmayan olduğu gibi kalır. Varsayılan biçimler `%d.%m.%Y`, `%H:%M`.
- Harf harf yazmada satır sonu **Shift+Enter**.
- Yapıştırmada panonun tüm HGLOBAL biçimleri yedeklenip ~150 ms sonra geri yüklenir; yedekleme başarısızsa harf harf yazmaya düşülür.
- Varsayılan kısayollar: duraklat `ctrl+alt+p`, arama `ctrl+alt+space`.
- Diller: tr ve en eksiksiz; de, es, fr, pt, ru eksik anahtarlarda en'e düşer.

## Review Focus

1. **Shift basılıyken tetikleme** (`;Adr` yazarken Shift hâlâ basılı): Backspace'ler Shift+Backspace olur, Ctrl+V yanlış gider. Beklenen: genişletme önce modifier'ların bırakılmasını bekler (en çok 500 ms), sonra açıkça bırakır. → Task 6 testi `test_waits_for_and_releases_modifiers`.
2. **Genişletme sırasında kullanıcı yazmaya devam ediyor / KısaYol kendi yazdığını görüyor**: Kendi enjekte ettiği tuşlar tampona girerse zincirleme genişleme olur. Beklenen: genişletme süresince matcher beslenmez, bitince sıfırlanır. → Task 7 testi `test_suspended_hook_does_not_feed_matcher`.
3. **Türkçe Q klavyede AltGr karakterleri** (`@` = AltGr+Q, `€`, `{`): Windows AltGr'yi Ctrl+Alt olarak bildirir; kural "Ctrl/Alt kombinasyonu tamponu sıfırlar" bunları yutar. Beklenen: AltGr ile üretilen yazılabilir karakter tampona eklenir. → Task 7 testi `test_altgr_character_is_fed`.
4. **Pano başka uygulamada kilitli** (OpenClipboard başarısız): Beklenen: pano dokunulmadan harf harf yazılır. → Task 6 testi `test_paste_falls_back_to_typing_when_backup_fails`.
5. **Bozuk ya da elle düzenlenmiş `snippets.json`**: Beklenen: uygulama açılır, bozuk dosya `snippets.json.bak` olarak saklanır, örnek kalıplarla devam edilir; geçersiz tek kayıtlar (eksik alan, geçersiz tetikleyici) atlanır ya da devre dışı alınır. → Task 2 testleri `test_corrupt_file_is_backed_up` ve `test_invalid_entries_skipped`.

  - `@dataclass Match(snippet: Snippet, delete_count: int, suffix: str)` — `delete_count` = silinecek karakter sayısı, `suffix` = sonda yeniden yazılacak bitiş karakteri (`""` sembollüde).

`feed` algoritması (testlerin tam belirlemediği sıra):
```
append ch (buffer max 64, baştan kırp)
1) en uzun sembollü tetikleyici t için buffer.endswith(t) → Match(t, len(t), "") ; reset
2) ch in TERMINATORS ise: w = buffer[:-1]'in sonundaki en uzun isalnum() dizisi
   w boş değil ve bare tetikleyici == w ise → Match(s, len(w)+1, ch) ; reset
   (kelime başı koşulu isalnum dizisinin tamamını almakla sağlanır: "Paslm" → w="Paslm")
3) None
```
